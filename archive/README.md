# Архив проекта

Все материалы, по которым сделаны исследование и итоги проекта: запросы, сырые данные, скрипты и Excel-файлы с расчётами. Их сохранили в репозитории, чтобы данные можно было взять отсюда, а не воспроизводить заново.

| Папка | Что внутри | Где описано |
|---|---|---|
| [`research/`](research/) | `sql/` — запросы исследования, номер в имени файла совпадает с номером раздела; `data/` — датасеты и Excel-файлы с расчётами в Power Query | [исследование](../docs/ru/research.md) |
| [`results/`](results/) | сырые выгрузки специалиста за сравниваемые периоды, скрипты сборки датасетов, запросы, финальные датасеты периодов, книги сравнения Power Query | [итоги проекта](../docs/ru/results.md), [`results/README.md`](results/README.md) |

Запросы выгрузок, по которым работает специалист, лежат не здесь, а в [`sql/`](../sql/).
