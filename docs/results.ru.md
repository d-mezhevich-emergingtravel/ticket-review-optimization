# 📊 Итоги проекта

Документ подводит итоги перехода на новый workflow проверки тикетов, построенный на выводах [исследования](research.md). Новый workflow направляет проверку на тикеты, где ошибка наиболее вероятна и значима, и за счёт этого сокращает объём ручной работы. Итоги показывают, как изменились объём проверки и её результат.

## 🧭 Как проводилось сравнение

- Сравниваются одни и те же недели 2025 и 2026 года, чтобы исключить влияние сезонности.
- Источник данных — файлы выгрузок, по которым сотрудник проводил проверку. Тикеты из них обрабатываются аналитическим SQL-запросом. Запрос собирает по каждому тикету действия сотрудника за неделю выгрузки и три следующие недели: изменения платежей, письма на сверку и флаги диспута.
- Перед сравнением данные нормированы.
- Датасеты двух периодов сравниваются в Excel, расчёты выполняются в Power Query.

## 3. Продуктовый workflow
